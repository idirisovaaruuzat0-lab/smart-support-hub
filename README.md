
# Smart Support Hub

Учебная веб-панель команды поддержки программного продукта.

Система помогает управлять внедрениями, регистрировать инциденты, контролировать сроки SLA, создавать заявки на сопровождение и планировать релизы.

**Демо:** https://idirisovaaruuzat0-lab.github.io/smart-support-hub/

**Репозиторий:** https://github.com/idirisovaaruuzat0-lab/smart-support-hub

## Возможности

- **Панель:** 4 показателя и графики Chart.js.
- **Внедрения:** этапы и процент готовности.
- **Инциденты:** приоритеты, статусы, поиск, фильтрация и контроль SLA.
- **Заявки:** четыре вида сопровождения.
- **Релизы:** история версий и формирование CHANGELOG.
- Светлая и тёмная темы.
- Адаптивная вёрстка.
- Сохранение данных в localStorage.

## Запуск проекта

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта в Visual Studio Code.
3. Откройте `index.html` через расширение Live Server.
