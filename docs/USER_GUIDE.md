# Руководство пользователя

## Назначение
Smart Support Hub помогает команде поддержки вести внедрения, регистрировать инциденты,
контролировать сроки решения (SLA) и планировать новые версии продукта.

## Как зарегистрировать инцидент
1. Откройте страницу «Инциденты».
2. Введите описание проблемы.
3. Выберите приоритет: критический (4 ч), высокий (8 ч), средний (24 ч), низкий (72 ч).
4. Нажмите «Создать инцидент».
5. Нажмите «В работу», когда начнёте решать проблему.
6. Когда проблема решена, нажмите «Решить». Система покажет, уложились ли вы в срок.

В столбце «Срок» видно, сколько времени осталось до нарушения SLA. Найти нужный инцидент
помогает поиск и фильтр по статусу.

## Как создать заявку на изменение
1. Откройте страницу «Заявки».
2. Введите название и выберите вид: корректирующее, адаптивное, совершенствующее или профилактическое.
3. Укажите целевую версию, например v1.3.0.
4. Нажмите «Создать заявку».
5. Кнопкой в строке переводите заявку по статусам: новая, запланирована, выполнена.

## Как выпустить новую версию
1. Откройте страницу «Релизы».
2. Выберите уровень: patch (исправления), minor (новая возможность) или major (несовместимые изменения).
3. Впишите изменения, по одному на строке, и нажмите «Выпустить релиз».
4. Кнопка «Скопировать CHANGELOG» готовит текст для файла CHANGELOG.md.

## Как сбросить данные
Кнопка «Сбросить данные» внизу бокового меню возвращает учебные данные.

## Куда обратиться
По вопросам работы системы создайте Issue в репозитории проекта на GitHub.
